# Friction Timer v2.3.1

Fix the return window missing from Manage defaults.

- Enable **Use a default return window** to save a return window for new apps, including 0 to disable it.
- Copy the return window from a saved app, reload saved defaults, and discard unsaved edits.
- Apply the saved return window to selected existing apps without changing unticked settings.
- Preserve existing app settings and saved defaults during the update. The new default remains unticked until selected.

The ARM64 APK supports Android 7 and newer and updates this fork's release builds in place. No reinstall or data reset is needed.
