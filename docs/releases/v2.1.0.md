# Friction Timer v2.1.0

Feed-app recommendations, optional reminders during a visit, a compact setup flow, and updated Android branding.

## Recommendations and setup

- Show installed, unconfigured Facebook, Instagram, TikTok, YouTube, X, Mastodon, Threads, Bluesky, Reddit, and Snapchat at the top of home. Include supported regional TikTok and modified YouTube packages.
- Keep Add any app available, hide empty recommendations, and open setup without enabling anything automatically.
- Select and scroll to the chosen app when opening setup from a recommendation or editing an existing configuration.
- Keep editor actions visible, with internal scrolling for long lists/content or small screens.
- Hide permissions once all are enabled; show the section again when setup needs attention.
- Replace the author/email footer with a link to this fork.

## Optional session reminders

- Enable reminders separately for any app; default off, with a changeable 10-minute interval.
- Validate positive whole-minute intervals and migrate existing local configurations safely.
- Count foreground time after Proceed, or immediately when no wait is needed. Repeat quiet notifications showing total elapsed session minutes, updating one notification.
- Reset timing and clear notifications when leaving the app or turning off the screen. Stop reminders when configuration is removed/disabled or the service stops.
- Explain missing notification permission and provide settings recovery, including older Android versions.
- No usage history or analytics added.

## Installation notes

Android 7+ and ARM64 are required for this APK. This fork uses a new release key and cannot replace upstream/debug builds signed with another key in place. Uninstalling an existing build deletes its local settings; keep it installed if you need those settings.

Browser tests simulate the native bridge. Native reminders and overlays were also exercised on a connected device using a debug build. Every manufacturer's battery policy and permission transition has not been verified.
