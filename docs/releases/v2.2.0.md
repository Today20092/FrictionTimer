# Friction Timer v2.2.0

Save reusable app defaults and apply the same settings across configured apps.

## App defaults

- Set defaults for new apps, including unlimited duration and session reminder preferences.
- Apply the same settings to selected apps when editing existing configurations.
- Keep defaults manageable from the app settings screen.

## Distribution

- Publish a signed ARM64 APK and SHA-256 checksum as a GitHub Release.
- The fixed `FrictionTimer-arm64.apk` asset always points to the latest release.
