# Friction Timer v2.3.0

- Briefly switch away from an unlimited session and return without repeating the waiting timer.
- Adjust **Return window (seconds)** for each app in the Timing step. The default is 30 seconds; set 0 to require a new wait after leaving.
- Keep separate return windows when multitasking between tracked apps. Turning off the screen clears the windows; unfinished countdowns still require the wait.
- Preserve existing app settings during the update, adding the 30-second return default. Finite session durations continue to work as before.
- Correct Rust reminder defaults and saved-message error diagnostics, and simplify internal imports and borrowing.

The ARM64 APK supports Android 7 and newer. Install it over this fork's existing release to retain settings. Builds signed with another key cannot be updated in place; uninstalling deletes local settings.
